# Energy Command Centre 0.1.0-alpha.12

This release replaces the baked dashboard artwork with a clean smart-home scene and moves all changing information into live Home Assistant overlays.

## What changed

- Replaces the old image with a valid 1672 × 941 scenery-only PNG containing no text, dates, sun, moon, controls, labels, arrows, cables or power values.
- Adds a real local date and clock generated by the browser.
- Drives the sun or moon along the sky arc from Home Assistant's `sun.sun` timing data.
- Adds the current moon phase, remaining daylight/night time and remaining solar forecast when available.
- Uses live wind speed and direction and converts the displayed speed to mph.
- Adds stars only during the live night state.
- Keeps all solar, house, grid, battery and EV cable values as independent live overlays.
- Preserves the **I have an EV** choice.
- Fixes automatic five-second refreshes resetting the Home Assistant scroll position.
- Respects reduced-motion browser settings.

## Updating

Update through HACS, restart Home Assistant, then hard-refresh the Energy Command Centre page.
